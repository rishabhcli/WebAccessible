# WebAccessible Demo Runbook

## Cloud Preflight

1. Open `/ready` and confirm EverOS and Snowflake are authorized and Browserbase is configured.
2. Confirm the W3C checkbox target and W3C radio fallback are reachable through a managed Browserbase session.
3. Confirm the Snowflake migrations and Streamlit app are deployed.
4. Start a participant session for the same opaque user ID used by the caregiver view.

## Live Sequence

1. Start `Choose sandwich ingredients` as a cold teach run.
2. Open the Browserbase Live View and request help.
3. Follow one sentence at a time and use the real W3C checkboxes.
4. Wait for verified completion and the EverOS indexing state.
5. Refresh routines, open the readable skill, and start its replay revision.
6. Complete the same task through selector-first guidance.
7. Open the Snowflake caregiver view and select the exact cold and warm runs.

## Truth Boundaries

- Margaret performs every click.
- A warm matching step has no model call.
- Empty or unsynchronized data says `No verified data`.
- Browserbase, EverOS, or Snowflake failure remains visible and is never replaced by a fixture.
